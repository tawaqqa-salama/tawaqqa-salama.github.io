## الربط الحالي (نشاط → إشغال)
- مطعم/مقهى → تجمعات
- مجمع تجاري → تجاري
- مكاتب → مكاتب
- تعليمي → تعليمي
- مصنع → صناعي متوسط
- مستودع → تخزين متوسط
- عمائر سكنية / فندق → سكني/فندقي
- مواقف → مواقف
- محطة وقود → استخدام خاص Ch.23

## ماذا يحدث عند اختيار الخيارات؟
عند تغيير **نوع النشاط** أو **تفصيل الأدوار** (وبالتالي عدد الأدوار ومساحة المبنى) تُحدَّث لوحة الاشتراطات فوراً وتشمل:
- تصنيف الإشغال ومستوى الخطر
- إلزام/عتبات المرشات والإنذار
- حماية الأدراج والمواسير الرأسية حسب عدد الأدوار
- تنبيهات خاصة (مواقف، تجمعات، صناعي متعدد الأدوار…)

> هذه طبقة مساعدة تشغيلية؛ التقرير النهائي يراجع النص الكامل للكود.
