# مكتبة الأنشطة

**الغرض:** تعريف أنشطة المنشآت لأغراض السلامة من الحريق، وربط كل نشاط بأنظمة إلزامية/اختيارية/غير مناسبة، وبالوثائق والتقارير المطلوبة.  
**الربط:** `ref_activity_types` · `compliance_rules.activity_type_id` · [EKB الباب ٣](../EKB-v1.0.md).

---

## مخطط حقول سجل النشاط

| الحقل | النوع المنطقي | إلزامي | الوصف |
|-------|---------------|--------|--------|
| `activity_code` | نص قصير فريد | نعم | مثل `ACT-COMM` |
| `name_ar` | نص | نعم | الاسم بالعربية |
| `name_en` | نص | نعم | الاسم بالإنجليزية |
| `occupancy_class` | نص/مرجع | نعم | فئة الإشغال الأساسية |
| `risk_level` | تعداد | نعم | منخفض / متوسط / عالٍ / عالٍ جداً |
| `required_systems` | قائمة | نعم | أنظمة يجب توفرها (أو شرط عتبة) |
| `optional_systems` | قائمة | لا | تُضاف حسب المساحة/الخطر/الجهة |
| `forbidden_systems` | قائمة | لا | غير مناسبة أو محظورة في السياق الاعتيادي |
| `required_docs` | قائمة | نعم | وثائق تصميم/ترخيص |
| `required_reports` | قائمة | نعم | تقارير دورة المشروع |
| `area_triggers` | نص | لا | عتبات مساحة/ارتفاع تغيّر الإلزام |
| `hazmat_flags` | قائمة | لا | إن وُجدت مواد خطرة شائعة |
| `notes` | نص | لا | تحفظات امتثال |
| `ekb_version` | نص | نعم | إصدار EKB المرجعي |
| `is_active` | منطقي | نعم | تفعيل السجل المرجعي |

## ACT-COMM — تجاري (Commercial)

| الحقل | القيمة |
|--------|--------|
| الإشغال | تجاري / Mercantile |
| الخطر | متوسط (يرتفع مع التخزين الداخلي أو المطاعم) |
| أنظمة إلزامية | نظام إنذار حريق مناسب لحجم المحل/المجمع؛ طفايات حسب الخطر؛ رشاشات عند تجاوز عتبات المساحة/الارتفاع/النوع وفق SBC والجهة المختصة؛ إضاءة طوارئ ولوحات مخارج |
| أنظمة اختيارية | شفط دخان للممرات الطويلة أو الأتريوم؛ أنظمة مطابخ إن وُجد مطبخ تجاري؛ مراقبة مرتبطة بالإنذار |
| محظور/غير مناسب | غمر CO₂ في فراغات بيع مأهولة؛ إخفاء نقاط الإنذار اليدوية خلف التشطيبات |
| وثائق | مخططات معمارية وهندسية؛ حساب حمل إشغال؛ مواصفات أنظمة؛ مخطط إخلاء للمجمعات |
| تقارير | عرض سعر؛ تقرير فني؛ تقرير زيارة؛ تقرير تفتيش؛ تقرير نهائي |
| عتبات شائعة | مساحة كبيرة أو طوابق متعددة → مراجعة إلزام الرشاشات والإنذار الصوتي/المرئي |
| ملاحظات | المحلات داخل المولات تتبع اشتراطات المجمع بالإضافة لاشتراطات المحل |

## ACT-RES — سكني (Residential)

| الحقل | القيمة |
|--------|--------|
| الإشغال | سكني |
| الخطر | منخفض إلى متوسط (يرتفع في الأبراج والمجمعات) |
| أنظمة إلزامية | كواشف دخان حسب نوع الوحدة؛ طفايات حيث تُطلب؛ مخارج وسلالم محمية حسب الارتفاع؛ رشاشات وإنذار مركزي في المباني متعددة الطوابق وفق العتبات |
| أنظمة اختيارية | إنذار مرتبط بغرفة حراسة للمجمعات؛ ضغط سلالم؛ أنظمة مطابخ مركزية إن وُجدت |
| محظور/غير مناسب | أنظمة إطفاء صناعية ثقيلة داخل الوحدات دون مبرر؛ قفل مخارج الطوارئ |
| وثائق | مخططات معمارية؛ تفاصيل فواصل حريق بين الوحدات؛ مخططات سلامة للمبنى المشترك |
| تقارير | زيارة موقع؛ متابعة نواقص؛ تقرير نهائي؛ شهادة إنجاز عند الإغلاق |
| ملاحظات | التمييز بين فيلا فردية وبرج سكني جوهري في تحديد الأنظمة |

## ACT-IND — صناعي (Industrial)

| الحقل | القيمة |
|--------|--------|
| الإشغال | صناعي / مصنعي |
| الخطر | عالٍ (يعتمد على العملية والمواد) |
| أنظمة إلزامية | تقييم خطر؛ رشاشات أو نظام بديل معتمد حسب التصنيف؛ إنذار مناسب (دخان/حرارة/لهب)؛ طفايات؛ مخارج قريبة من مناطق العمل؛ عند السوائل: رغوة أو حماية مكافئة |
| أنظمة اختيارية | كشف لهب؛ أنظمة خاصة للخطوط الإنتاجية؛ شفط دخان صناعي؛ مراقبة |
| محظور/غير مناسب | ماء غير متحكم على معدات كهربائية حية دون تصميم؛ خلط أنظمة غير متوافقة في نفس الخلية دون فصل |
| وثائق | وصف العملية؛ قائمة مواد (SDS)؛ تصنيف مناطق؛ حسابات هيدروليكية؛ HAZMAT إن لزم |
| تقارير | تقرير فني؛ تفتيش؛ صيانة دورية؛ تقرير نهائي |
| hazmat_flags | مذيبات، زيوت، غبار قابل للاشتعال، غازات |

## ACT-HOT — فندقي (Hotel)

| الحقل | القيمة |
|--------|--------|
| الإشغال | فندقي / سكني عام |
| الخطر | متوسط إلى عالٍ (نوم + كثافة زوار + مطابخ) |
| أنظمة إلزامية | رشاشات في غالبية الحالات حسب الارتفاع والحجم؛ إنذار صوتي/مرئي يصل للغرف؛ نقاط يدوية؛ طفايات؛ إضاءة طوارئ؛ أنظمة إطفاء أغطية مطابخ للمطابخ التجارية |
| أنظمة اختيارية | شفط دخان للدهاليز والأتريوم؛ لوحات تكرار عند الاستقبال؛ ربط مع إدارة الفندق |
| محظور/غير مناسب | عوائق ديكور على المخارج؛ كواشف غير مناسبة في الحمامات دون مبرر تصميم |
| وثائق | مخطط إخلاء لكل طابق؛ حساب إشغال القاعات؛ مواصفات غرف وأنظمة |
| تقارير | زيارات مرحلية؛ اختبار إنذار؛ تقرير نهائي؛ برنامج صيانة |
| ملاحظات | القاعات متعددة الأغراض تُعامل كإشغال تجميع عند الفعاليات |

## ACT-WH — مستودع (Warehouse)

| الحقل | القيمة |
|--------|--------|
| الإشغال | تخزين |
| الخطر | متوسط إلى عالٍ جداً حسب المادة وارتفاع التخزين |
| أنظمة إلزامية | تصنيف التخزين (سلعة/ارتفاع/طريقة)؛ رشاشات بكثافة مناسبة أو ESFR عند الانطباق؛ إنذار؛ طفايات؛ فواصل حريق/خلايا عند اللزوم |
| أنظمة اختيارية | رغوة للسوائل؛ كشف خاص؛ تهوية دخان؛ أنظمة رفوف مدمجة الحماية |
| محظور/غير مناسب | تكديس يحجب الرشاشات؛ تخزين مواد غير متوافقة دون فصل؛ الاعتماد على طفايات فقط في تخزين عالٍ المخاطر |
| وثائق | مخطط رفوف وارتفاعات؛ تصنيف سلع؛ حسابات هيدروليكية؛ خطة فصل مواد |
| تقارير | تقرير فني؛ تفتيش؛ صيانة؛ زيارة تحقق بعد تغيير التخزين |
| عتبات | أي زيادة في ارتفاع التخزين أو تغيير السلعة → إعادة تقييم فوري للتصميم |

## ACT-FUEL — محطة وقود (Fuel Station)

| الحقل | القيمة |
|--------|--------|
| الإشغال | مخاطر خاصة |
| الخطر | عالٍ جداً |
| أنظمة إلزامية | أنظمة إطفاء مناسبة للمناطق (رغوة/خاص حسب الجزء)؛ طفايات مناسبة لصنف الوقود؛ إنذار/كشف حيث يُطلب؛ مسافات فصل؛ صرف وطفايات أرضية حسب الاشتراط؛ لافتات ومنع مصادر اشتعال |
| أنظمة اختيارية | كشف أبخرة؛ مراقبة؛ أنظمة إيقاف مضخات مرتبطة بالكشف |
| محظور/غير مناسب | رش ماء تقليدي كحل وحيد على خزانات/مناطق توزيع دون تصميم معتمد؛ تخزين أسطوانات LPG خارج الاشتراط |
| وثائق | مخطط موقع بمسافات الفصل؛ تفاصيل خزانات؛ مواصفات أنظمة خاصة؛ خطة طوارئ |
| تقارير | تقرير فني؛ تفتيش دوري إلزامي؛ صيانة أنظمة الرغوة/الخاص |
| ملاحظات | المتجر الملحق يُقيَّم كإشغال تجاري بالإضافة لاشتراطات المحطة |

## ACT-DC — مركز بيانات (Data Center)

| الحقل | القيمة |
|--------|--------|
| الإشغال | تقنية معلومات / مخاطر أصول عالية |
| الخطر | عالٍ من حيث قيمة الأصول واستمرارية الخدمة (احتمال الحريق قد يكون منخفضاً نسبياً لكن الأثر مرتفع) |
| أنظمة إلزامية | كشف دخان مبكر (غالباً عينة هواء VESDA أو مكافئ)؛ إنذار؛ إطفاء بالعامل النظيف و/أو رشاشات pre-action حسب استراتيجية الحماية؛ فصل طاقة طارئ مخطط؛ طفايات نظيفة/CO₂ محدودة الاستخدام حسب الفراغ |
| أنظمة اختيارية | إطفاء موضعي للخزائن؛ ربط BMS؛ كشف حرارة نقاط ساخنة |
| محظور/غير مناسب | غمر مائي مباشر غير متحكم على المعدات الحية؛ CO₂ في فراغات مأهولة باستمرار دون ضوابط صارمة |
| وثائق | مخططات كهرباء وتبريد؛ استراتيجية إطفاء؛ حساب تركيز عامل نظيف؛ إجراءات الإخلاء والإعادة للتشغيل |
| تقارير | تقرير فني؛ اختبار إحكام غرفة؛ اختبار إنذار؛ صيانة دقيقة مجدولة |
| ملاحظات | غرف البطاريات تُقيَّم كمخاطر منفصلة (انظر مكتبة المواد الخطرة) |

| الحقل | القيمة |
|--------|--------|
| الإشغال | تعليمي |
| الخطر | متوسط (يرتفع في المختبرات والورش) |

| أنظمة اختيارية | شفط دخان للقاعات الكبرى؛ أنظمة خاصة للمختبرات؛ إنذار مرتبط بإدارة المدرسة |

| وثائق | مخطط إخلاء؛ حساب إشغال الفصول والقاعات؛ اشتراطات مختبرات إن وُجدت |
| تقارير | زيارة؛ تفتيش؛ تدريب إخلاء موثّق؛ تقرير نهائي |
| ملاحظات | رياض الأطفال قد تتطلب اعتبارات إضافية لمسارات الإخلاء والإشراف |

| الرمز | رشاشات | إنذار | خاص/رغوة/نظيف | شفط دخان |

| ACT-COMM | حسب العتبة | إلزامي غالباً | مطابخ إن وُجدت | اختياري |
| ACT-RES | حسب الارتفاع/النوع | كواشف ± مركزي | نادر | نادر |

| ACT-EDU | حسب الحجم | إلزامي | مختبرات | قاعات |

## قواعد إدخال نشاط جديد

1. تخصيص `activity_code` فريد.  
2. ربط فئة إشغال ومستوى خطر.  
3. تعبئة الأنظمة الثلاث (إلزامي/اختياري/غير مناسب) بمراجع كود.  
4. إنشاء أو تحديث `compliance_rules` المرتبطة.  
5. إضافة سيناريو في [scenarios.md](./scenarios.md) إن كان النشاط عالي الأثر.  
6. تسجيل التحديث في [updates-log.md](./updates-log.md).
