# مكتبة السيناريوهات

**الغرض:** سيناريوهات تصميم وامتثال جاهزة للاستخدام من قبل المهندسين ومحرك القرارات.  
**الربط:** أنشطة · مخاطر · قرارات · [EKB](../EKB-v1.0.md).

## سيناريو ١ — مدرسة (Educational)

| الحقل | المحتوى |
|--------|---------|
| الرمز | SCN-EDU-01 |
| النشاط | `ACT-EDU` |
| المبنى | `BLD-EDU` |
| الإشغال | فصول + مختبرات + قاعة متعددة + فناء |
| المخاطر الرئيسية | ازدحام إخلاء؛ حريق مختبر؛ إنذار غير مسموع في أجنحة بعيدة؛ قفل مخارج بالخطأ الأمني |
| أنظمة أساسية | إنذار واضح لكل جناح؛ طفايات؛ إضاءة طوارئ ولوحات مخارج؛ رشاشات حسب عتبة الحجم/الارتفاع؛ حماية خاصة للمختبر إن وُجدت كيماويات |
| أنظمة حسب الحالة | شفط دخان للقاعة الكبرى؛ إنذار مرتبط بإدارة المدرسة؛ خزائن كيماويات |
| وثائق حرجة | مخطط إخلاء ونقاط تجميع؛ حمل إشغال الفصول؛ قائمة مواد المختبر |
| قرارات نموذجية | اختيار عنونة عند تعدد الأجنحة؛ فصل المختبر كمنطقة خطر |
| أخطاء شائعة | مخارج مغلقة أثناء الدوام؛ تخزين مواد تنظيف قابلة للاشتعال تحت الدرج |
| مؤشرات نجاح | اختبار إنذار مسموع في أبعد فصل؛ تجربة إخلاء موثّقة؛ طفايات سارية |

## سيناريو ٢ — مستشفى (Healthcare)

| الحقل | المحتوى |
|--------|---------|
| الرمز | SCN-HSP-01 |
| النشاط | رعاية صحية (يرتبط بـ `BLD-HSP`؛ يُنشأ `ACT-HSP` لاحقاً إن لزم) |
| الإشغال | مرضى، طاقم، زوار؛ مناطق عمليات وتشخيص وتخزين أكسجين |
| المخاطر الرئيسية | صعوبة إخلاء المرضى؛ دخان يعيق الأروقة؛ أكسجين يرفع شدة الحريق؛ إنذار يسبب هلعاً غير مُدار |
| أنظمة أساسية | رشاشات واسعة غالباً؛ إنذار مرحلي/مراقَب؛ مقصورات دخان؛ إخلاء أفقي لمناطق ملاجئة؛ طفايات؛ ضوابط مناطق الأكسجين |
| أنظمة حسب الحالة | أنظمة خاصة لغرف معينة؛ لوحة تكرار عند غرفة الطوارئ/الأمن |
| وثائق حرجة | خطة إخلاء أفقية؛ مناطق الدخان؛ سياسات أعمال ساخنة |
| قرارات نموذجية | عدم تبني إخلاء رأسي كامل كخيار أول؛ ضبط تتابعات الأبواب حتى لا تُغلق مسارات الإخلاء الأفقي |
| أخطاء شائعة | تخزين كرتون في مخارج؛ تعطيل باب حريق بأوتاد؛ أعمال صيانة دون تصريح |
| مؤشرات نجاح | اختبار مرحلية الإنذار؛ سلامة فواصل الدخان؛ تدريب طاقم التمريض على الإخلاء الأفقي |

|--------|---------|

| النشاط | `ACT-HOT` |

| المخاطر الرئيسية | حريق ليلي في غرفة؛ انتقال دخان بالدهاليز؛ اشتعال زيوت مطبخ؛ كثافة قاعة في فعالية |
| أنظمة أساسية | رشاشات؛ إنذار يصل للغرف (صوت/مرئي حسب التصميم)؛ MCP؛ طفايات؛ أنظمة أغطية مطابخ؛ إضاءة طوارئ |
| أنظمة حسب الحالة | شفط دخان لأثريوم؛ لوحات تكرار عند الاستقبال؛ حماية مواقف |
| وثائق حرجة | مخطط إخلاء لكل طابق؛ حساب إشغال القاعة؛ برنامج صيانة شفاطات |
| قرارات نموذجية | معاملة القاعة كإشغال تجميع وقت الفعاليات؛ Pre-action فقط إن وُجدت أصول خاصة (نادراً في الغرف) |
| أخطاء شائعة | ديكور يحجب MCP؛ كواشف بعد السقف المستعار دون إعادة تنسيق؛ باب درج مفتوح دائماً دون آلية معتمدة |
| مؤشرات نجاح | اختبار إنذار غرف عيّنة؛ نجاح تجربة إخلاء جزئي؛ صيانة مطبخ موثّقة |

## كيفية استخدام السيناريو في المشروع

1. انسخ السيناريو الأقرب كقائمة تحقق أولية.  
2. احذف ما لا ينطبق وأضف معطيات الموقع.  
3. اربط القرارات ذات الأرقام `DEC-*`.  
4. حدّث المخاطر المتبقية في سجل المخاطر.  
5. إن تكرر سيناريو جديد، أضفه هنا وسجّل `UPD-*`.
