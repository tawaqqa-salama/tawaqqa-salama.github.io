# مكتبة أنظمة الإطفاء

**الغرض:** مقارنة أنظمة الإطفاء الثابتة وشبه الثابتة لاختيار مناسب للنشاط والخطر.  
**الربط:** [EKB الباب ٧](../EKB-v1.0.md) · أنشطة ومخاطر ومواد خطرة.

---

## ١. الرشاشات المائية (Sprinkler)

| البند | المحتوى |
|--------|---------|
| الاستخدام | معظم الإشغالات التجارية والسكنية المتعددة والصناعية والمستودعات (حسب التصنيف) |
| المزايا | موثوقية عالية، قبول واسع من الجهات، تكلفة دورة حياة معقولة، تفعيل موضعي غالباً |
| القيود | ضرر ماء على الأصول الحساسة؛ قد لا يناسب وحدهُ سوائل معينة أو معدات حية دون تصميم؛ يتطلب مصدراً ماءً وضغطاً كافيين |
| ملاحظات | كثافة/مساحة، نوع الرأس (قياسي، سريع، ESFR)، عوائق السقف، حالة الأنابيب الرطبة/الجافة/pre-action |

---

## ٢. الأنابيب الرأسية (Standpipe)

| البند | المحتوى |
|--------|---------|
| الاستخدام | مبانٍ متعددة الطوابق، مساحات كبيرة لدعم فرق الإطفاء |
| المزايا | يوفّر نقاط هجوم ماء بطوابق علوية؛ يكمّل الرشاشات |
| القيود | لا يغني عن الرشاشات حيث تكون إلزامية؛ يعتمد على تدريب واستخدام صحيح؛ يحتاج صيانة صمامات وخراطيم |
| ملاحظات | تصنيف النظام (I/II/III حسب المرجع)، ضغط متبقي عند الأبعد |

---

## ٣. أنظمة الخراطيم (Hose Systems)

| البند | المحتوى |
|--------|---------|
| الاستخدام | تدخل أولي من شاغلين مدرَّبين أو كجزء من standpipe |
| المزايا | بساطة نسبية، استجابة سريعة لحريق صغير |
| القيود | فعالية محدودة؛ خطر على غير المدرَّبين؛ صيانة بكرات وصناديق |
| ملاحظات | لا تُستخدم كبديل عن الحماية التلقائية المطلوبة بالكود |

---

## ٤. العامل النظيف (Clean Agent)

| البند | المحتوى |
|--------|---------|
| الاستخدام | غرف تحكم، مراكز بيانات، فراغات أصول حساسة للماء |
| المزايا | إخماد دون بقايا ماء ضارة غالباً؛ مناسب للإلكترونيات عند التصميم الصحيح |
| القيود | تكلفة؛ يتطلب إحكام غرفة ووقت احتفاظ؛ اعتبارات سلامة الأشخاص والتركيز؛ صيانة أسطوانات وتسرب |
| ملاحظات | راجع NFPA 2001 أو المرجع المعتمد؛ اختبار إحكام؛ إنذار قبل الصرف |

---

## ٥. ثاني أكسيد الكربون CO₂

| البند | المحتوى |
|--------|---------|
| الاستخدام | مخاطر كهربائية أو صناعية في فراغات غير مأهولة أو بضوابط صارمة |
| المزايا | فعّال، لا يترك residual سائلاً |
| القيود | خطر اختناق عالٍ على الأشخاص؛ قيود مشددة على الأماكن المأهولة؛ متطلبات إنذار وإخلاء قبل الصرف |
| ملاحظات | لا يُختار لفراغات عامة مأهولة كحل افتراضي |

---

## ٦. الرغوة (Foam)

| البند | المحتوى |
|--------|---------|
| الاستخدام | سوائل قابلة للاشتعال: محطات وقود، خزانات، بعض المستودعات الصناعية |
| المزايا | يخنق سطح السائل ويقلل إعادة الاشتعال |
| القيود | صيانة نسب الخلط؛ توافق بيئي؛ تدريب؛ تصميم فوهات ونسب |
| ملاحظات | اختيار نوع الرغوة (AFFF وغيرها) حسب السائل واللوائح البيئية السارية |

---

## ٧. رذاذ الماء (Water Mist)

| البند | المحتوى |
|--------|---------|
| الاستخدام | تطبيقات معتمدة بديلاً أو مكملاً في فراغات محددة |
| المزايا | استهلاك ماء أقل؛ تبريد جيد في بعض السيناريوهات |
| القيود | يتطلب تصميماً واعتماداً متخصصين؛ ليس بديلاً تلقائياً عن الرشاشات التقليدية دون قبول الجهة |
| ملاحظات | راجع قوائم الاعتماد وطراز النظام |

---

## ٨. أنظمة المطابخ (Kitchen Suppression)

| البند | المحتوى |
|--------|---------|
| الاستخدام | أغطية قلي، شوايات، مطابخ تجارية وفندقية |
| المزايا | مصممة لزيوت الطبخ؛ ترتبط غالباً بفصل الحرارة/الوقود |
| القيود | لا تغني عن تنظيف الشفاطات؛ صيانة فوهات وخزان الوكيل |
| ملاحظات | تكامل مع إنذار المبنى؛ طفايات مكمّلة مناسبة للزيوت |

---

## ٩. أنظمة خاصة (Special Hazard Systems)

| البند | المحتوى |
|--------|---------|
| الاستخدام | مخاطر فريدة: خزائن كهربائية، خطوط طلاء، مخاطر طيران، أرشيف حساس، … |
| المزايا | مصممة للخطر المحدد |
| القيود | تكلفة، تعقيد اعتماد، قطع غيار، تدريب |
| ملاحظات | تتطلب مواصفة مشروع وموافقة جهة مختصة عند اللزوم |

---

## مصفوفة اختيار سريعة

| السياق | خيار أول شائع | بديل/مكمل |
|--------|----------------|-----------|
| مكتب/تجاري عام | رشاشات + إنذار | Standpipe حسب الارتفاع |
| مستودع سلع عامة | رشاشات/ESFR | — |
| سوائل قابلة للاشتعال | رغوة ± رشاشات مصممة | طفايات مناسبة |
| مركز بيانات | Clean Agent و/أو Pre-action | VESDA |
| مطبخ تجاري | نظام غطاء رطب كيميائي | طفاية زيوت |
| غرفة كهرباء غير مأهولة | CO₂ أو نظيف | حسب سياسة السلامة للأشخاص |

---

## توثيق القرار

عند اختيار النظام: اذكر النشاط، الخطر، المادة، مرجع الكود، وسبب استبعاد البدائل في التقرير الفني أو سجل القرار الهندسي.
