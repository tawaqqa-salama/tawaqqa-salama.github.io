# مكتبة المعدات

**الغرض:** مرجع لمعدات أنظمة الإطفاء والإنذار من حيث المواصفات والشهادات والصيانة.  
**الربط:** `ref_manufacturers` · معدات المشروع · [EKB الباب ٩](../EKB-v1.0.md).

---

## ١. مضخات الحريق

| البند | التفصيل |
|--------|---------|
| الأنواع | كهربائية، ديزل، جockey (ضغط المحافظة) |
| مواصفات أساسية | التدفق المقنن، الضغط المقنن، منحنى الأداء، NPSH، قدرة المحرك، زمن إقلاع الديزل |
| شهادات شائعة | UL/FM عند اشتراط المشروع/الجهة؛ مطابقة مواصفة EQ-PUMP |
| تركيب | غرفة مضخات وفق التفاصيل التنفيذية؛ صمامات اختبار؛ تهوية وصرف |
| صيانة | تشغيل اختباري أسبوعي/حسب البرنامج؛ فحص وقود وبطاريات الديزل؛ سجل تشغيل؛ صيانة سنوية متخصصة |

## ٢. خزانات ماء الحريق

| البند | التفصيل |
|--------|---------|
| الأنواع | أرضي، علوي، خرساني، معدني، حسب المشروع |
| مواصفات | السعة (≥ الطلب × مدة الاحتياطي)، مواد مقاومة، فيض، تفريغ، قياس مستوى، حماية من التجمد حيث يلزم |
| شهادات/قبول | مطابقة المواصفة الهندسية؛ اختبار تسرب عند التسليم |
| صيانة | تفتيش دوري للتسرب والتآكل؛ نظافة؛ التحقق من صمامات العزل وعدم الإغلاق الخاطئ |

## ٣. الرشاشات (Sprinkler Heads)

| البند | التفصيل |
|--------|---------|
| الأنواع | استجابة قياسية، استجابة سريعة، ESFR، مغطاة/مخفية، جافة، … |

| قواعد | لا تُطلى؛ تُستبدل عند التلف أو انتهاء الصلاحية للمغطاة حسب الشركة؛ مسافات وتركيب حسب التصميم |
| صيانة | تفتيش بصري؛ استبدال الرؤوس المصطدمة/المتآكلة؛ عدم تخزين مواد تحجب الرش |

## قواعد قبول المعدات

1. مطابقة المواصفة المعتمدة للعقد.  
2. شهادة سارية للطراز.  
3. وثائق تركيب وتشغيل باللغة المتفق عليها.  
4. إدراج في برنامج الصيانة قبل التسليم النهائي.  
5. أي بديل يتطلب موافقة مهندس ومقارنة منحنى/أداء/شهادة.
