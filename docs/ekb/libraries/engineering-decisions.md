# مكتبة القرارات الهندسية

**الغرض:** توحيد طريقة اتخاذ وتوثيق القرارات الفنية المتعلقة بأنظمة السلامة من الحريق.  
**الربط:** محرك القرارات · `compliance_exceptions` · [EKB](../EKB-v1.0.md).

---

## إطار القرار المعياري (٦ خطوات)

| الخطوة | السؤال | مخرجات |
|--------|--------|--------|
| ١. المعطيات | ما النشاط، المساحة، الارتفاع، المواد، الإشغال، القيود؟ | بطاقة معطيات مشروع |
| ٢. الإلزام | ماذا تفرض SBC/الجهة/العقد؟ | قائمة متطلبات إلزامية |
| ٣. البدائل | ما الأنظمة الممكنة تقنياً؟ | ٢–٣ بدائل من مكتبات الإطفاء/الإنذار |
| ٤. المخاطر | ما الاحتمال والأثر لكل بديل؟ | تقييم من مكتبة المخاطر |
| ٥. الاختيار | ما الأنسب مع المبرر المرجعي؟ | قرار + مراجع |
| ٦. الاستثناء | هل نحتاج انحرافاً؟ وهل هو مسموح؟ | نموذج استثناء أو إغلاق دون استثناء |

## سجل قرار — الحقول

| الحقل | وصف |
|-------|------|
| `decision_id` | DEC-YYYY-NNN |
| المشروع / المبنى / المنطقة | نطاق القرار |
| موضوع القرار | مثال: نوع الإطفاء لغرفة الخوادم |
| المعطيات الملخصة | … |
| البدائل المدروسة | أ / ب / ج |
| القرار | المختار |
| المبررات | فنية + امتثال + تشغيل |
| المراجع | أكواد، EKB، حسابات |
| المخاطر المتبقية | وما ضوابطها |
| اعتماد | اسم وصلاحية وتاريخ |
| مراجعة لاحقة | عند تغيير استخدام/تخزين |

## أمثلة قرارات للمرحلة الأولى

### DEC-EX-001 — مركز بيانات: Pre-action مقابل رطب تقليدي

| البند | المحتوى |
|--------|---------|
| المعطيات | غرفة خوادم حساسة للماء، إشغال فني محدود، قيمة أصول عالية |
| إلزام | إنذار مبكر + حماية معتمدة حسب الجهة/التأمين |
| البدائل | (أ) رشاشات رطبة (ب) Pre-action (ج) Clean Agent فقط (د) Clean Agent + Pre-action |
| القرار النموذجي | غالباً (د) أو (ب)+(ج) حسب الميزانية وإحكام الغرفة |
| مبرر | تقليل الإطلاق العرضي للماء مع الإبقاء على طبقة حماية مائية احتياطية و/أو إخماد نظيف سريع |
| خطر متبقٍ | تعقيد صيانة — يُغطى بعقد صيانة دقيقة |

### DEC-EX-002 — مستودع: رفع كثافة الرش بعد زيادة ارتفاع التخزين

| البند | المحتوى |
|--------|---------|
| المعطيات | تغيير ارتفاع التخزين من حد منخفض إلى أعلى من حد التصميم الأصلي |
| القرار | إيقاف زيادة التخزين فوراً حتى إعادة الحساب؛ ترقية رؤوس/شبكة أو خفض الارتفاع |
| مبرر | التصميم الهيدروليكي مرتبط بالارتفاع والسلعة؛ التغيير دون مراجعة يبطل الافتراضات |
| ربط | خطأ DES-01 ودرس LL-2026-001 |

### DEC-EX-003 — محطة وقود: رغوة للمناطق مقابل ماء فقط

| البند | المحتوى |
|--------|---------|
| المعطيات | منصات توزيع + خزانات |
| القرار | أنظمة خاصة/رغوة حسب جزء الموقع + طفايات مناسبة؛ عدم اعتماد ماء تقليدي كحل وحيد |
| مبرر | طبيعة السوائل والأبخرة واشتراطات الجهة |

### DEC-EX-004 — مدرسة: إنذار بسيط مقابل عنونة

| البند | المحتوى |
|--------|---------|
| المعطيات | مبنى متعدد الأجنحة، كثافة طلاب |
| القرار | عنونة للمباني المتوسطة/الكبيرة لتسريع تحديد موقع الإنذار وتقليل إخلاء عشوائي واسع |
| مبرر | زمن الاستجابة وإدارة الإخلاء |

### DEC-EX-005 — استثناء مسافة رأس رشاش لعائق إنشائي

| البند | المحتوى |
|--------|---------|
| الشرط | فقط إن سمحت القاعدة بـ `is_exception_allowed` |
| القرار | إما نقل الرأس، أو رأس إضافي، أو قبول استثناء ببديل معادل موثّق |
| مبرر | الحفاظ على تغطية مائية دون إضعاف التصنيف |

## قواعد توثيق

1. لا قرار حرج دون رقم `decision_id` في ملف المشروع.  
2. القرارات التي تغيّر النظام تحدّث المخططات والحسابات في نفس الإصدار.  
3. الاستثناءات تُغلق بحالة اعتماد واضحة؛ المعلق لا يُنفَّذ ميدانياً.  
4. يُمنع الاعتماد على محادثة شفهية أو اقتراح ذكاء اصطناعي غير معتمد كقرار نهائي.
