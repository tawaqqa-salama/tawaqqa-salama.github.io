# مكتبة الإنذار وأجهزة الكشف والإشعار

**الغرض:** مرجع لمكوّنات أنظمة إنذار الحريق والإضاءة الإرشادية للطوارئ.  
**الربط:** [EKB الباب ٨](../EKB-v1.0.md) · NFPA 72 كمرجع مكمل · SBC/الجهة المختصة كمقدَّم.

---

## ١. الكواشف (Detectors)

| النوع | الاستخدام | مزايا | قيود/تنبيهات |
|-------|-----------|--------|--------------|
| دخان كهروضوئي/تأييني | فراغات عامة، مكاتب، دهاليز | كشف مبكر للدخان | إنذارات كاذبة من غبار/بخار؛ تباعد حسب السقف |
| عينة هواء (VESDA وما شابه) | مراكز بيانات، فراغات عالية الحساسية | إنذار مبكر جداً بمستويات تنبيه متعددة | تكلفة؛ معايرة وصيانة أنابيب أخذ العينات |
| حرارة ثابتة/معدّل ارتفاع | مطابخ، مواقف، بيئات غبار | أقل تأثراً بالبخار/الغبار | أبطأ من الدخان في حرائق كثيرة |
| لهب (UV/IR) | صناعي، وقود، لهب مفتوح متوقع | استجابة سريعة للهب | حساسية لمصادر متداخلة؛ تصميم مجال رؤية |
| غاز | LPG/غازات أخرى | إنذار تسرب قبل الاشتعال | اختيار حساس للغاز الصحيح وارتفاع التركيب |

**قواعد تباعد عامة:** اتبع الكود/المواصفة المعتمدة؛ راعِ ارتفاع السقف، العوائق، تدفق التكييف، والأسقف المستعارة (فوق/تحت).

---

## ٢. نقاط الإنذار اليدوية (MCP / Manual Call Points)

| البند | التفصيل |
|--------|---------|
| الوظيفة | تشغيل الإنذار يدوياً عند مشاهدة حريق |
| المواقع الشائعة | عند مخارج الطوابق، مسارات الإخلاء، نقاط تجمع داخلية حسب التصميم |
| ارتفاع التركيب | حسب المواصفة المعتمدة وسهولة الوصول |
| الأخطاء الشائعة | إخفاؤها بالديكور؛ وضعها خلف أبواب مغلقة؛ عدم تمييزها بصرياً |

---

## ٣. الأجراس والصوتات (Bells / Sounders)

| البند | التفصيل |
|--------|---------|
| الوظيفة | إشعار صوتي للشاغلين |
| التصميم | مستوى صوت فوق الضوضاء المحيطة بالقدر المطلوب؛ تغطية كل المناطق المطلوبة |
| أنواع | أجراس تقليدية، صوتات إلكترونية، رسائل صوتية مسجّلة في الأنظمة المتقدمة |
| قيود | في البيئات الصاخبة الصناعية قد يلزم أجهزة أعلى أو إشعار مرئي مكمّل |

---

## ٤. الأجهزة المرئية (Strobes / Beacons)

| البند | التفصيل |
|--------|---------|
| الوظيفة | إشعار لضعاف السمع أو في مناطق الضجيج |
| التصميم | شدة وميض وتباعد حسب المرجع؛ تجنب الإفراط المزعج دون مقتضى |
| التكامل | غالباً مع الصوتات كوحدات مشتركة |

---

## ٥. لوحات التحكم (FACP) ولوحات التكرار

| البند | التفصيل |
|--------|---------|
| الوظيفة | مركز مراقبة الحالة، الإنذار، الأعطال، والتحكم |
| الموقع | مكان آمن، وصول لفرق الإطفاء/التشغيل، لافتات واضحة |
| الأنواع | تقليدية (مناطق) / عنونة (أجهزة فردية) |
| الاحتياط | بطاريات احتياطية لمدة مطلوبة؛ مراقبة أعطال الشبكة الكهربائية |
| لوحات تكرار | استقبال فنادق، غرف حراسة، مداخل دفاع مدني حسب التصميم |

---

## ٦. وحدات الإدخال/الإخراج (I/O Modules)

| البند | التفصيل |
|--------|---------|
| الوظيفة | ربط الإنذار بأنظمة أخرى: تشغيل مضخة، إغلاق أبواب حريق، إيقاف تكييف، تشغيل شفط دخان، تحرير أبواب مغناطيسية |
| تصميم | منطق واضح (ماذا يحدث عند إنذار/عطل)؛ اختبار التكامل عند التسليم |
| خطر شائع | تتابع خاطئ يغلق مخرجاً أو يعطّل تهوية مطلوبة |

---

## ٧. إضاءة الطوارئ

| البند | التفصيل |
|--------|---------|
| الوظيفة | إضاءة مسارات الإخلاء عند فقدان الكهرباء |
| المتطلبات الإطارية | مدة تشغيل كافية؛ مستوى إضاءة عند الأرضية/المسار؛ اختبار دوري |
| التغذية | وحدات ذاتية أو نظام مركزي حسب المشروع |
| أخطاء | تركيب دون اختبار؛ حجب وحدات بتشطيبات لاحقة |

---

## ٨. لوحات المخارج (Exit Signs)

| البند | التفصيل |
|--------|---------|
| الوظيفة | دلالة اتجاه المخرج الآمن |
| المتطلبات | وضوح، إضاءة مستمرة أو طوارئ حسب الكود، عدم تضليل الاتجاه |
| أخطاء | أسهم خاطئة بعد تعديل التقسيمات الداخلية؛ إخماد الإضاءة للديكور |

---

## مصفوفة اختيار نوع النظام

| حجم/تعقيد المبنى | نظام شائع | سبب |
|-------------------|-----------|------|
| محل صغير | تقليدي بسيط + كواشف/يدوي | تكلفة وتعقيد أقل |
| مبنى متعدد الطوابق/مول | عنونة | تحديد موقع الجهاز والصيانة |
| مركز بيانات | عنونة + VESDA | إنذار مبكر ودقة |
| صناعي صاخب | كواشف مناسبة + مرئي/صوتي عالٍ | تجاوز ضوضاء الآلات |

---

## اختبارات تسليم أساسية

1. إنذار من كل نوع جهاز ممثل.  
2. قياس مستويات صوت في أبعد نقطة.  
3. اختبار بطاريات وفقد طاقة.  
4. اختبار تتابعات I/O.  
5. التحقق من رسائل اللوحة ووضوح المناطق/العناوين.
