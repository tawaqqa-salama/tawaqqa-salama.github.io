# مكتبة النماذج والتقارير

**الغرض:** تعريف نماذج العمل والتقارير الهندسية/التشغيلية وسياسة إصداراتها.  
**الربط:** `documents` · `version_label` · [EKB الباب ١٢](../EKB-v1.0.md).

---

## سياسة تاريخ الإصدارات (ملزمة للمرحلة الأولى)

| القاعدة | التفصيل |
|---------|---------|
| الترقيم | `Major.Minor` داخل `version_label` (مثال 1.0 ثم 1.1 ثم 2.0) |
| المسودة | قابلة للتعديل دون رقم اعتماد نهائي |
| الاعتماد | الإصدار المعتمد **يُجمَّد**؛ أي تعديل جوهري ينشئ إصداراً جديداً |
| الحذف | لا يُحذف إصدار معتمد؛ يُؤرشف |
| التتبع | يُسجَّل المعدّل، التاريخ، سبب التغيير، ومرجع المشروع |
| الربط | نسخة المرفق تُحفظ مع `checksum` عند التوفر (DDS) |

---

## ١. عرض السعر (Quotation)

| البند | المحتوى |
|--------|---------|
| الغرض | تسعير خدمات استشارية و/أو أنظمة وتوريد |
| حقول أساسية | رقم العرض، العميل، المشروع، بنود وكميات، أسعار، ضريبة، إجمالي، صلاحية العرض، استثناءات النطاق |
| مرفقات | نطاق فني ملخص، افتراضات |
| إصدار | كل إعادة تسعير جوهرية = إصدار جديد؛ الإشارة لرقم الإصدار السابق |

---

## ٢. العقد (Contract)

| البند | المحتوى |
|--------|---------|
| الغرض | إطار التزام قانوني/تجاري للتنفيذ |
| حقول أساسية | رقم العقد، أطراف، نطاق، مدة، جدول دفعات، مسؤوليات، ضمان، إنهاء |
| مرفقات | نطاق فني، جداول كميات، مواصفات |
| إصدار | النسخة الموقّعة ثابتة؛ التغيير عبر ملحق (Addendum) مرقّم |

---

## ٣. التقرير الفني (Technical Report)

| البند | المحتوى |
|--------|---------|
| الغرض | تصميم أو مراجعة أنظمة السلامة |
| حقول أساسية | وصف المشروع، نشاط، مراجع كود وطبعات، أنظمة مقترحة، حسابات، استنتاجات، تحفظات |
| مرفقات | أوراق حساب، مخططات، جداول معدات |
| إصدار | مسودة → قيد مراجعة → معتمد؛ رفض المراجعة يعيد لمسودة برقم فرعي جديد |

---

## ٤. معلومات المخططات (Drawing Index / Plan Info)

| البند | المحتوى |
|--------|---------|
| الغرض | فهرسة الرسومات ومراجعاتها |
| حقول أساسية | رقم الرسم، العنوان، المقياس، تاريخ، مراجعة، معدّ، معتمد |
| إصدار | يتبع مراجعة CAD/BIM؛ لا يعتمد تقرير يناقض فهرس المخططات |

---

## ٥. تقرير زيارة موقع (Site Visit)

| البند | المحتوى |
|--------|---------|
| الغرض | رصد ميداني للوضع القائم أو التنفيذ |
| حقول أساسية | تاريخ، فريق، موقع GPS إن توفر، ملاحظات، صور، مخاطر فورية، توصيات |
| إصدار | تقرير مستقل لكل زيارة؛ لا تُستبدل الزيارة السابقة |

---

## ٦. تقرير متابعة (Follow-up)

| البند | المحتوى |
|--------|---------|
| الغرض | تتبع إغلاق النواقص |
| حقول أساسية | قائمة بنود، مسؤول، تاريخ استحقاق، حالة (مفتوح/مغلق)، دليل الإغلاق |
| إصدار | تحديثات متسلسلة مع حفظ تاريخ الحالات (لا طمس الإغلاقات السابقة) |

---

## ٧. التقرير النهائي (Final Report)

| البند | المحتوى |
|--------|---------|
| الغرض | خلاصة اكتمال الأعمال الفنية للمرحلة |
| حقول أساسية | نطاق مكتمل، نتائج اختبارات، مطابقة، تحفظات متبقية، توصيات تشغيل |
| إصدار | إصدار معتمد واحد للإغلاق + ملاحق عند الحاجة |

---

## ٨. شهادة الإنجاز (Completion Certificate)

| البند | المحتوى |
|--------|---------|
| الغرض | إثبات إنجاز نطاق محدد |
| حقول أساسية | رقم شهادة فريد، نطاق، تاريخ، توقيعات، مرجع عقد/مشروع |
| إصدار | غير قابلة لإعادة الاستخدام لنطاق مختلف؛ إلغاء بشهادة ملغاة موثّقة إن لزم |

---

## ٩. تقرير التفتيش (Inspection)

| البند | المحتوى |
|--------|---------|
| الغرض | فحص وفق قائمة تحقق |
| حقول أساسية | بنود المطابقة، عدم المطابقة، خطورة، إجراء تصحيحي |
| ربط | `inspection_checklist` في DDS عند الأتمتة لاحقاً |
| إصدار | كل جولة تفتيش محفوظة كتاريخ |

---

## ١٠. تقرير الصيانة (Maintenance)

| البند | المحتوى |
|--------|---------|
| الغرض | تنفيذ برنامج صيانة وقائية/تصحيحية |
| حقول أساسية | معدة، إجراء، نتيجة، قطع غيار، موعد الصيانة التالية، فني |
| إصدار | سلسلة زمنية؛ أساس لإثبات العناية أمام الجهة/التأمين |
