# مكتبة الرسومات المرجعية

**الغرض:** فهرسة أنواع الرسومات والتفاصيل المرجعية التي تدعم التصميم والمراجعة والتسليم — دون أن تكون ملفات CAD مرفقة إلزامياً في المرحلة الأولى.  
**الربط:** [EKB الباب ١٦](../EKB-v1.0.md) · مرفقات `dwg`/`rvt`/`ifc` في DDS.

---

## ١. مخططات نموذجية (Typical Drawings)

| الرمز | الرسم | المحتوى الأدنى | استخدامه |
|-------|--------|----------------|----------|
| DWG-PR-01 | غرفة مضخات نموذجية | مسقط، مقاطع، ترتيب مضخات، صمامات، صرف، تهوية | مرجع تصميم ومراجعة مسافات |
| DWG-TK-01 | خزان ماء حريق | توصيلات، فيض، قياس مستوى | تنسيق مدني/ميكانيك |
| DWG-SP-01 | توزيع رشاشات لطابق مكتبي | شبكة، تباعد، صاعدات | نقطة انطلاق للمشاريع المشابهة |
| DWG-SP-02 | حماية مستودع رفوف | قطاع يوضح المسافة تحت الرشاش وارتفاع التخزين | ضبط التخزين مع المالك |
| DWG-AL-01 | مخطط إنذار طابقي | كواشف، MCP، صوتات، لوحة | تنسيق كهرباء ومعمار |
| DWG-EG-01 | مسارات إخلاء | مخارج، عرض، نقاط تجميع | تدريب وملصقات |
| DWG-FU-01 | مخطط موقع محطة وقود | مسافات فصل، مناطق خطرة | امتثال موقع |
| DWG-DC-01 | غرفة حاسوب/بيانات | كشف مبكر، إطفاء، إحكام | استراتيجية حماية أصول |

## ٢. تفاصيل CAD / BIM

| الرمز | التفصيل | الصيغة المفضلة | ملاحظات |
|-------|---------|----------------|----------|
| DET-FP-01 | اختراق أنبوب في جدار مقاوم للحريق | DWG + بطاقة منتج | يربط بنظام السدّ المعتمد |
| DET-HP-01 | تعليق أنابيب حريق | DWG | مسافات دعم |
| DET-SP-01 | رأس رشاش في سقف مستعار | DWG/RVT | فوق/تحت البلاطة المستعارة |
| DET-AL-01 | رموز أجهزة إنذار أسطورة قياسية | DWG | توحيد رموز الشركة |
| DET-DR-01 | باب حريق ومغلق كهربائي مرتبط بالإنذار | DWG/RVT | تتابع I/O |
| BIM-CL-01 | تصنيف عناصر الحريق في النموذج | RVT/IFC | أكواد نظام لكل عنصر |

**قاعدة BIM:** كل عنصر سلامة يحمل رمزاً يطابق جدول المعدات ورقم الدائرة حيث ينطبق.

## ٤. متطلبات جودة الرسم المرجعي

| المتطلب | التفصيل |
|---------|---------|
| وحدة القياس | مترية ما لم يُتفق خلاف ذلك |
| رقم مراجعة | واضح في الختم |
| المراجع | كود/مواصفة الطبعة |
| الأسطورة | رموز موحدة |
| التحذير | «مرجعي — يُعدَّل حسب مشروع فعلي» |

- [ ] يوضح المناسيب والارتفاعات الحرجة

## ٦. إدارة الملفات

المسار التشغيلي المقترح للمرفقات (عند التخزين لاحقاً): ربط المرفق بـ `documents`/`attachments` مع `file_type` = `dwg` أو `rvt` أو `pdf`، وذكر `ekb_ref` مثل `DWG-PR-01` في الوصف.
