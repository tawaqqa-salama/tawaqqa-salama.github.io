# مكتبة الدروس المستفادة

**الغرض:** تحويل خبرات المشاريع إلى معرفة قابلة لإعادة الاستخدام داخل منصة توقع.  
**الربط:** `knowledge_articles.lessons_learned` · [EKB الباب ١٥](../EKB-v1.0.md).

---

## قالب تسجيل درس مستفاد

| الحقل | وصف المحتوى المطلوب |
|-------|----------------------|
| `lesson_id` | رمز فريد مثل `LL-2026-001` |
| تاريخ التسجيل | YYYY-MM-DD |
| رمز المشروع | من سجل المشاريع |
| العميل/القطاع | دون إفشاء سرّي غير لازم |
| النشاط / نوع المبنى | `ACT-*` / `BLD-*` |
| المرحلة | تصميم / ترخيص / تنفيذ / تسليم / تشغيل |
| المشكلة | ماذا حدث؟ |
| السبب الجذري | لماذا حدث؟ (5 Whys موجز) |
| الأثر | تأخير، رفض، تكلفة، خطر سلامة |
| الإجراء التصحيحي | ما الذي أُصلح في المشروع |
| الإجراء الوقائي | ما الذي يمنع التكرار في مشاريع قادمة |
| الدرس (جملة واحدة) | خلاصة قابلة للتذكير |
| تحديث EKB المقترح | أي باب/مكتبة تُحدَّث |
| الكلمات المفتاحية | وسوم بحث |
| الحالة | مقترح / معتمد مؤسسياً |

## عينة ١ — `LL-2026-001` مستودع كيماويات

| الحقل | المحتوى |
|--------|---------|
| التاريخ | ٢٠٢٦-٠٣-١٢ |
| المشروع | (مثال) مشروع مستودع مواد صناعية |
| النشاط / المبنى | `ACT-WH` / `BLD-WH` |
| المرحلة | ترخيص / مراجعة جهة |
| المشكلة | تأخر الاعتماد بسبب تخزين مواد غير متوافقة في نفس الخلية دون فاصل أو مصفوفة توافق |
| السبب الجذري | اعتماد مخطط معماري عام دون إدخال قائمة المواد والكميات في مرحلة التصميم الأولى |
| الأثر | رفض مراجعة، إعادة تصميم فصل خلايا، تأخير جدولة توريد الرشاشات |
| الإجراء التصحيحي | إعداد مصفوفة توافق + إعادة تقسيم التخزين + تحديث كثافة الرش لكل خلية |
| الإجراء الوقائي | إلزام قائمة مواد وSDS كمدخل بوابة قبل إصدار المخططات للجهة |
| الدرس | **لا تُصمَّم حماية المستودع قبل تثبيت خريطة المواد والتوافق.** |
| تحديث EKB | تأكيد بند الفصل في `hazardous-materials.md` وسيناريو مستودع كيماويات |
| الوسوم | مستودع، كيماويات، توافق مواد، رفض اعتماد |

| السبب الجذري | تنسيق ضعيف بين مقاول الإنذار ومقاول الأسقف؛ اعتماد إحداثيات كواشف على مخطط قديم قبل تعديل الدكتات |

| تحديث EKB | تفاصيل تنفيذ في `installation-details.md` و`alarm-devices.md` |
| الوسوم | فندق، إنذار، سقف مستعار، اختبار تسليم |

## قواعد إدارة الدروس

1. لا تُنشر معلومات سرية للعميل دون تخفيف.  
2. الدرس المعتمد يتحول إلى فقرة في FAQ أو الأخطاء الشائعة عند التكرار ≥ مرتين.  
3. الدروس عالية الخطورة تُراجع في اجتماع الجودة الفنية خلال أسبوعين من الاعتماد.  
4. كل درس معتمد يُنشأ له مقال معرفة أو يُحدَّث مقال قائم في `knowledge_articles`.
