# مكتبة التفاصيل التنفيذية

**الغرض:** ضوابط تنفيذ ميداني لأنظمة الإطفاء والإنذار المرتبطة بجودة التركيب وقبول الجهات.  
**الربط:** [EKB الباب ١١](../EKB-v1.0.md) · زيارات الموقع · تقارير النواقص.

---

## ١. غرفة المضخات

| العنصر | متطلب تنفيذي |
|--------|----------------|
| الموقع والوصول | وصول واضح لفرق الصيانة والإطفاء؛ أبواب بعرض مناسب لنقل المعدات |
| التهوية | كافية للمحركات والديزل؛ عادم الديزل لخارج المبنى بشكل آمن |
| الصرف | صرف تسربات واختبار دون إغراق الغرفة أو المعدات الكهربائية |
| الكهرباء | تغذية مستقرة؛ لوحة واضحة؛ فصل طارئ؛ تأريض |
| الترتيب | مسافات صيانة حول المضخة؛ عدم تخزين مواد غريبة في الغرفة |
| اللافتات والاختبار | لافتات تشغيل؛ نقطة اختبار تدفق؛ مانومترات صالحة |
| الأمان | منع مصادر اشتعال قرب وقود الديزل؛ طفاية مناسبة داخل/قرب الغرفة |

---

## ٢. الخزانات

| العنصر | متطلب تنفيذي |
|--------|----------------|
| الأساسات | تحمل الوزن الكامل عند الامتلاء؛ منع هبوط غير محسوب |
| التوصيلات | إمداد، فيض، تفريغ، تنفيس حسب التصميم؛ صمامات بمؤشرات |
| الحماية | من التآكل، الاصطدام، والتجمد حيث ينطبق |
| القياس | مؤشر مستوى مقروء؛ إنذار مستوى منخفض إن شُرط |
| النظافة | خلو من مخلفات البناء قبل الملء؛ فلترة عند الحاجة |
| العزل الخاطئ | منع إغلاق صمام الإمداد دون مراقبة/لافتة قفل |

---

## ٣. الرشاشات والأسقف

| العنصر | متطلب تنفيذي |
|--------|----------------|
| المسافات | حسب التصميم بين الرؤوس والجدران والعوائق |
| العوائق | دكتات، كمرات، لافتات معلّقة — تقييم حجب الرش |
| الاتجاه | رأس معلق/قائم/جانبي حسب الاعتماد |
| التشطيب | الرؤوس المغطاة تُركَّب حسب تعليمات الشركة؛ لا طلاء على العنصر الحساس |
| الأسقف المستعارة | رؤوس تحت السقف المستعار و/أو أعلاه حسب حماية الفراغ |
| التخزين | الإبقاء على المسافة الحرة أسفل الرؤوس في المستودعات |

---

## ٤. الأعمال الكهربائية المرتبطة بالسلامة

| العنصر | متطلب تنفيذي |
|--------|----------------|
| دوائر الإنذار | فصل عن دوائر عامة؛ حماية قواطع مميزة باللافتات |
| التتابعات | إيقاف تكييف، تحرير أبواب، تشغيل شفط — حسب مصفوفة I/O المعتمدة فقط |
| الطوارئ | تغذية إضاءة طوارئ ولوحة إنذار ومضخة حسب التصميم |
| الكابلات | مسارات محمية؛ عدم مشاركة عشوائية مع قوة عالية دون فصل |
| الاختبار | محاكاة فقد قدرة والتحقق من البطاريات والانتقال |

---

## ٥. المولدات الاحتياطية

| العنصر | متطلب تنفيذي |
|--------|----------------|
| زمن الإقلاع | يلبي متطلبات الأحمال الحرجة للسلامة |
| الأحمال | مضخة كهربائية (إن اعتمدت على المولد)، لوحة إنذار، إضاءة طوارئ — حسب الدراسة |
| التهوية والوقود | عادم آمن؛ تخزين وقود بضوابط المادة الخطرة |
| الاختبار | تشغيل دوري تحت حمل؛ سجلات |

---

## ٦. الأنابيب والدعم

| العنصر | متطلب تنفيذي |
|--------|----------------|
| الميل والتفريغ | إمكانية تفريغ وصرف النظام للصيانة حيث يلزم |
| التفريغ الهوائي | نقاط تحرّر هواء في النقاط العالية للشبكات الرطبة عند الحاجة |
| التعليق | مسافات دعم معتمدة؛ اهتزاز مضخات معزول |
| التعريف | ألوان/لافتات دوائر حريق؛ ترقيم صمامات يطابق المخطط |
| الاختبار | ضغط هيدروستاتيكي؛ إصلاح تسرب قبل الإغلاق المعماري |

---

## ٧. الاختراقات المقاومة للحريق (Fire-rated Penetrations)

| العنصر | متطلب تنفيذي |
|--------|----------------|
| المبدأ | كل اختراق في جدار/سقف مصنّف يُسدّ بنظام معتمد يعيد التصنيف الزمني |
| المواد | سدّادات/أطواق/مواد معتمدة؛ لا رغوة عشوائية غير مصنّفة |
| التوثيق | رقم نظام الاختراق، تصنيف الساعة، صورة قبل الإغلاق |
| أخطاء شائعة | ترك فتحات حول الأنابيب؛ خلط أنظمة غير متوافقة؛ إخفاء الاختراق دون فحص |

---

## ٨. تسلسل قبول تنفيذي موجز

1. مطابقة المخططات المعتمدة (As-built لاحقاً).  
2. اختبارات ضغط وتدفق وإنذار.  
3. التحقق من الاختراقات واللافتات.  
4. تدريب تشغيل أولي للعميل.  
5. تسليم ملفات O&M وشهادات المعدات.

---

## ٩. قائمة نواقص متكررة ميدانياً

| النقص | الإجراء |
|-------|---------|
| صمام إمداد مغلق | فتح + قفل مفتوح + إنذار مراقبة إن لزم |
| رأس رشاش محجوب بتخزين | إعادة ترتيب التخزين فوراً |
| MCP خلف ديكور | نقل/كشف النقطة |
| اختراق مفتوح | تطبيق نظام سدّ معتمد قبل التسليم |
| عدم تطابق عنونة الأجهزة مع الخريطة | تحديث اللوحة والمخطط |
