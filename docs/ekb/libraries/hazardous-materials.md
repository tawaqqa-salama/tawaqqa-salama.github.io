# مكتبة المواد الخطرة

**الغرض:** إرشاد هندسي لتصنيف وتخزين وإطفاء مواد خطرة شائعة في مشاريع منصة توقع.  
**الربط:** أنشطة صناعية/مستودعات/محطات/مطابخ/مراكز بيانات · [EKB الباب ٦](../EKB-v1.0.md).

> دائماً راجع ورقة بيانات السلامة (SDS) والكود المحلي. الجداول التالية إطارية وليست بديلاً عن تقييم موقع محدد.

---

## ١. ديزل (Diesel)

| البند | التفصيل |
|--------|---------|
| التصنيف | سائل قابل للاشتعال/الاشتعال حسب نقطة الوميض والتصنيف المحلي؛ وقود سائل شائع للمولدات والخزانات |
| التخزين | خزانات معتمدة؛ حاجز انسكاب (Bund) بسعة مناسبة؛ تهوية؛ منع مصادر اشتعال؛ لافتات؛ فصل عن المباني حسب المسافات |
| عامل الإطفاء | رغوة مناسبة للسوائل الهيدروكربونية؛ بودرة؛ CO₂ للمعدات المغلقة الصغيرة؛ طفايات مناسبة للتصنيف |
| أنظمة مسموحة | أنظمة رغوة ثابتة/شبه ثابتة؛ رشاشات مصممة للخطر إن اعتُمدت؛ كشف حراري/لهب حسب الموقع |
| أنظمة غير مناسبة | الاعتماد على ماء يبعثر البركة دون غطاء رغوي في انسكابات واسعة؛ تخزين دون صرف آمن |
| مؤشرات خطر | رائحة، بقع، ارتفاع حرارة مضخة وقود، أعمال لحام قرب الخزان |

---

## ٢. غاز البترول المسال LPG

| البند | التفصيل |
|--------|---------|
| التصنيف | غاز مسال قابل للاشتعال؛ أثقل من الهواء غالباً في التسرب |
| التخزين | أسطوانات/خزانات بمسافات فصل؛ تثبيت؛ تهوية منخفضة المستوى؛ كشف تسرب؛ منع الحفر/التصريف الذي يحبس الغاز دون تصميم |
| عامل الإطفاء | إيقاف التدفق أولاً إن أمكن؛ بودرة جافة؛ CO₂؛ ماء للتبريد على الأوعية المعرّضة للحرارة بحذر وبتدريب |
| أنظمة مسموحة | كشف غاز؛ تهوية؛ أنظمة إيقاف طارئ؛ طفايات مناسبة؛ حماية خزانات حسب الاشتراط |
| أنظمة غير مناسبة | حصر الكمية في غرفة مغلقة دون تهوية وكشف؛ تسخين الأسطوانات |
| مؤشرات خطر | صوت تسرب، صقيع على الصمام، رائحة مضافة، تركيز مرتفع على الكاشف |

---

## ٣. مذيبات (Solvents)

| البند | التفصيل |
|--------|---------|
| التصنيف | سوائل قابلة للاشتعال و/أو سامة و/أو متفاعلة حسب النوع (أسيتون، ثنر، …) |
| التخزين | خزائن مقاومة للحريق للكميات الصغيرة؛ تهوية؛ تأريض عند النقل؛ فصل عن المؤكسدات؛ كميات الحد الأدنى التشغيلية |
| عامل الإطفاء | رغوة مقاومة للكحول إن لزم؛ بودرة؛ CO₂؛ حسب SDS |
| أنظمة مسموحة | شفط محلي؛ رشاشات/رغوة حسب كمية الغرفة؛ كشف بخار عند الحاجة |
| أنظمة غير مناسبة | ماء قد ينشر بعض المذيبات الأخف دون تصميم؛ تخزين مختلط مع أحماض/مؤكسدات |
| مؤشرات خطر | بخار مرئي/رائحة قوية، صداع عاملين، تراكم عبوات مفتوحة |

---

## ٤. بطاريات (حمضية / ليثيوم أيون)

| البند | التفصيل |
|--------|---------|
| التصنيف | خطر كهربائي؛ خطر حراري وانفلات حراري لليثيوم؛ أبخرة/أحماض للأنواع التقليدية |
| التخزين | غرف مخصّصة؛ فصل عن المواد القابلة للاشتعال؛ تهوية؛ كشف دخان/حرارة؛ مسافات بين الصفوف؛ إجراءات شحن آمنة |
| عامل الإطفاء | للكهرباء التقليدية: CO₂/نظيف/بودرة حسب الحالة؛ لليثيوم: اتبع إرشاد الشركة المصنّعة والجهة المختصة (قد يشمل تبريد مائي متحكم في سيناريوهات محددة) |
| أنظمة مسموحة | كشف مبكر؛ فصل كهربائي؛ أنظمة غاز/نظيف للغرف؛ مراقبة حرارة |
| أنظمة غير مناسبة | غمر عشوائي دون إجراء؛ شحن فوق الطاقة الاستيعابية للغرفة؛ خلط بطاريات تالفة مع الجديدة |
| مؤشرات خطر | انتفاخ خلايا، رائحة، حرارة موضعية، إنذارات شاحن |

---

## ٥. كيماويات عامة (Industrial Chemicals)

| البند | التفصيل |
|--------|---------|
| التصنيف | متنوعة: قابلة للاشتعال، مؤكسدة، أكّالة، سامة، متفاعلة مع الماء… |
| التخزين | مصفوفة توافق؛ SDS لكل مادة؛ حاويات ثانوية؛ فصل أحماض/قواعد/مؤكسدات/قابلة للاشتعال؛ تهوية وPP E |
| عامل الإطفاء | **حسب SDS حصراً**؛ بعض المواد تتفاعل خطراً مع الماء |
| أنظمة مسموحة | أنظمة تحدد بعد تقييم كل مجموعة مواد؛ رشاشات أو خاص أو رغوة |
| أنظمة غير مناسبة | تصميم واحد لكل المستودع دون تقسيم؛ تجاهل مواد متفاعلة مع الماء |
| مؤشرات خطر | تلف عبوة، انسكاب، سخونة غير مبررة، رائحة غير معتادة |

---

## ٦. زيت الطبخ (Cooking Oil / Grease)

| البند | التفصيل |
|--------|---------|
| التصنيف | زيوت ودهون قابلة للاشتعال في المطابخ التجارية؛ تراكم دهون في الشفاطات خطر إضافي |
| التخزين/التشغيل | أحواض وأغطية؛ تنظيف دوري للشفاطات والمجاري؛ إبعاد المواد القابلة للاشتعال عن القلي |
| عامل الإطفاء | أنظمة رطبة كيميائية (Wet Chemical) لأغطية القلي؛ طفايات مناسبة لزيوت الطبخ (ليست ماء) |
| أنظمة مسموحة | نظام إطفاء غطاء مطبخ متصل بفصل مصدر الحرارة والوقود؛ إنذار |
| أنظمة غير مناسبة | ماء على زيت مشتعل (انتشار/خطر بخاري)؛ تعطيل نظام الغطاء للصيانة دون بديل مؤقت معتمد |
| مؤشرات خطر | اشتعال مقلاة، دخان كثيف، تراكم دهون مرئي في الشفاط |

---

## مصفوفة توافق سريعة (إطار مبسّط)

| مادة أ | مادة ب | التوافق |
|--------|--------|---------|
| ديزل | مؤكسدات قوية | غير متوافق — فصل |
| LPG | مصادر اشتعال/حفر حابسة | خطر عالٍ — ضوابط موقع |
| مذيبات | أحماض مؤكسدة | غير متوافق — فصل |
| بطاريات ليثيوم | مواد قابلة للاشتعال المجاورة | فصل ومسافة |
| كيماويات غير معروفة | أي مادة | امنع التخزين حتى SDS |
| زيت طبخ (تشغيل) | ماء كإطفاء أولي | غير مناسب |

---

## متطلبات توثيق عند وجود مواد خطرة

1. قائمة مواد وكميات قصوى.  
2. SDS محدّثة.  
3. مخطط تخزين وفصل.  
4. اختيار عامل الإطفاء بمبرر.  
5. تحديث النشاط/`compliance_rules` إن تغيّر التصنيف.
