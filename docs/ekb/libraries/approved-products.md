# مكتبة المنتجات المعتمدة (أمثلة)

**الغرض:** إطار لتسجيل منتجات ومصنّعين وشهادات وبدائل لأغراض ضبط الجودة الفنية في المشاريع.  
**الربط:** `ref_manufacturers` · [EKB الباب ١٧](../EKB-v1.0.md).

> **تنويه مهم:** جميع الأسماء والطرازات أدناه **أمثلة توضيحية للبنية والحقول فقط** وليست تزكية تجارية أو قائمة شراء إلزامية. يستبدلها كل مستأجر بقوائمه المعتمدة لديه وبما توافقه الجهة المختصة.

---

## حقول سجل المنتج

| الحقل | الوصف |
|-------|--------|
| `product_id` | رمز داخلي |
| الشركة المصنّعة | اسم المدرج في الشهادة |
| اسم المنتج / الطراز | كما في Listing |
| الفئة | مضخة / رشاش / لوحة / طفاية / كاشف / … |
| الشهادات | UL / FM / SASO / أخرى + أرقام |
| تاريخ انتهاء/مراجعة الشهادة | للمتابعة |
| نطاق الاستخدام | أنشطة/مخاطر مناسبة |
| قيود | أين لا يُستخدم |
| بدائل مكافئة | شروط التكافؤ (شهادة، منحنى، K-factor…) |
| الحالة | مسموح للعرض / موقوف / منتهي |

## قواعد إدراج منتج في قائمة المستأجر

1. شهادة سارية للطراز المحدد.  
2. ملاءمة للنشاط والخطر.  
3. توفر قطع غيار وخدمة محلية معقولة.  
4. موافقة هندسية مكتوبة عند الاستثناء من قائمة سابقة.  
5. إيقاف فوري عند سحب الشهادة أو بلاغ سلامة من الجهة المصنّعة.

## تكافؤ البدائل — الحد الأدنى للمقارنة

| الفئة | يجب تطابق/تكافؤ |
|-------|------------------|
| مضخة | Q, P, المنحنى، القدرة، الشهادة، نوع المحرك إن شُرط |
| رشاش | K، درجة الحرارة، نوع الاستجابة، التوجيه، الشهادة |
| لوحة | السعة، البروتوكول، الوظائف المطلوبة، الشهادة |
| طفاية | تصنيف الحريق، السعة، الاعتماد المحلي |

لا يُقبل البديل على أساس السعر وحده.
