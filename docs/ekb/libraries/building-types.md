# مكتبة أنواع المباني

**الغرض:** تصنيف أنواع المباني من منظور السلامة من الحريق ومتطلبات الأنظمة الشائعة.  
**الربط:** `ref_building_types` · [EKB الباب ٤](../EKB-v1.0.md).

## خصائص تصميمية مشتركة للمراجعة

| الخاصية | لماذا تهم السلامة |
|---------|-------------------|
| الارتفاع وعدد الطوابق | عتبات الرشاشات، الضغط، الإنذار، الإخلاء الرأسي |
| المساحة الطابقية | كثافة الأنظمة، عدد المخارج، مناطق الرش |
| نوع السقف/السقف المستعار | تباعد الكواشف والرشاشات والعوائق |
| وجود أتريوم | شفط دخان وانتقال دخان بين الطوابق |
| المواقف الملحقة | حماية منفصلة أو مدمجة حسب التصميم |
| غرف الخدمات | مضخات، كهرباء، مولدات — تفاصيل تنفيذية خاصة |

---

## قواعد الاختيار السريع

1. حدّد الاستخدام الرئيسي أولاً ثم الاستخدامات الثانوية.  
2. إن تساوى استخدامان في الأهمية، صمّم حسب **الأشد خطراً** أو افصل بفواصل حريق معتمدة.  
3. غيّر التصنيف عند تغيير الاستخدام التشغيلي (مثلاً مستودع ← تخزين سوائل).  
4. اربط النوع بنشاط `ACT-*` في مكتبة الأنشطة ولا تكتفِ بالوصف المعماري فقط.
