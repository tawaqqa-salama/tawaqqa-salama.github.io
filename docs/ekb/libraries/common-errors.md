## ٦. مسار معالجة موحّد عند اكتشاف خطأ

1. تصنيف الخطأ (تصميم/حساب/تنفيذ/وثائق).  
2. تقييم خطورة السلامة الفورية.  
3. إجراء احتوائي إن لزم (عزل، منع إشغال جزئي، إغلاق صمام بحذر…).  
4. تصحيح جذري وتوثيق.  
5. تسجيل درس مستفاد إن تكرر أو كان عالي الأثر.  
6. تحديث قاعدة معرفة أو قاعدة امتثال عند الحاجة.
