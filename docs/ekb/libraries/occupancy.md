## مبادئ حساب حمل الإشغال (إطار)

1. استخدم جداول الكثافة في الكود المعتمد للمشروع (SBC وما يُحال إليه).  
2. احسب لكل فراغ على حدة ثم جمّع حسب منطقة الإخلاء.  
3. القاعات متعددة الاستخدام: خذ **الأشد** بين الاستخدامات المتوقعة.  
4. لا تخلط بين «عدد الموظفين التشغيلي» و«الحمل التصميمي للإخلاء».  
5. وثّق الافتراضات في التقرير الفني ومخطط الإخلاء.

## علاقة الإشغال بالإنذار والإطفاء

| إذا كان الإشغال… | فغالباً يُركَّز على… |
|------------------|----------------------|
| عالي الكثافة (تجميع/تعليمي) | سرعة الإشعار، عروض المخارج، إدارة الحشود |
| تخزين عالٍ | كثافة الرش، ارتفاع التخزين، حجب الرشاشات |
| رعاية صحية | الإخلاء الأفقي، الإنذار المرحلي، فواصل الدخان |
| مخاطر خاصة | توافق عامل الإطفاء مع المادة، حماية الأفراد من العامل نفسه |
| فندقي/سكني ليلي | وصول الإنذار للنائمين، رشاشات، دهاليز محمية |
