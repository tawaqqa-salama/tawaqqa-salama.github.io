## إجراءات عند ظهور خطر حرج ميدانياً

1. تأمين الأرواح أولاً (إخلاء/فصل مصدر إن آمن).  
2. إبلاغ مسؤول السلامة والعميل.  
3. تسجيل ملاحظة زيارة بدرجة حرجة.  
4. قرار هندسي مكتوب خلال مهلة محددة.  
5. عدم إغلاق البند إلا بدليل معالجة.
