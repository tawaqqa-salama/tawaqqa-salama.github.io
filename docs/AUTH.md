# تسجيل الدخول والصلاحيات

المنصة تتطلب دخول موظف قبل استخدام أي صفحة.

## طرق الدخول
1. **إيميل + كلمة مرور**
2. **جوال سعودي `05xxxxxxxx` + كود تحقق**

## في الوضع التجريبي (بدون Supabase)
حسابات جاهزة تظهر في صفحة `/login`:

| الدور | الإيميل | كلمة المرور | الجوال |
|---|---|---|---|
| مدير | admin@tawaqqa.sa | Admin@123 | 0599776676 |
| مهندس | engineer@tawaqqa.sa | Eng@123 | 0500000002 |
| مبيعات | sales@tawaqqa.sa | Sales@123 | 0500000003 |
| محاسب | finance@tawaqqa.sa | Fin@123 | 0500000004 |

كود الجوال التجريبي يُعرض على الشاشة بعد الإرسال.

## الصفحات
- `/login` — الدخول
- `/me` — الصفحة الخاصة بالموظف الحالي
- `/u/?username=...` — صفحة موظف مخصصة (للنفس أو للمدير)
- `/settings/users` — إدارة الموظفين والصلاحيات (للمدير)

## الصلاحيات
تُحدد عبر الدور (`admin` / `engineer` / `sales` / `accountant` / `staff`) مع صلاحيات أقسام إضافية اختيارية، وأقسام تظهر في الصفحة الشخصية.

## مع Supabase الحقيقي
- فعّل Auth (Email + Phone OTP عبر مزود SMS)
- طبّق `scripts/sql/009_auth_users_roles.sql`
- اربط `public.users.auth_user_id` بحساب `auth.users`
