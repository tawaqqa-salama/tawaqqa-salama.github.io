## تطبيق المخطط

```bash
# يتطلب DATABASE_URL في .env.local
node scripts/apply-dds-schema.mjs
```

أو تشغيل ملفات SQL بالترتيب داخل `scripts/sql/`.

## التوافق مع النظام الحالي

المخطط يحافظ على الجداول المستخدمة اليوم (`clients`, `sales_*`, المحاسبة) ويضيف الكيانات الجديدة (الشركات، هيكل المشروع، الامتثال، المعرفة، الذكاء الاصطناعي، التدقيق، Multi-Tenant) دون كسر التطبيق الحالي.

## قاعدة المعرفة الهندسية (EKB)
